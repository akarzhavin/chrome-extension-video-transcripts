# 개인정보 처리방침 — Lingogram: Dual Subtitles & Transcript for YouTube

**시행일:** 2026년 6월 22일
**최종 업데이트:** 2026년 7월 13일

이 개인정보 처리방침은 **Lingogram: Dual Subtitles & Transcript for YouTube** 브라우저 확장 프로그램("확장 프로그램")이 수집하는 정보, 사용 방법, 저장 위치, 그리고 사용자가 가지는 선택권을 설명합니다.

---

## 요약(TL;DR)

* **계정 없이는 확장 프로그램이 사용자에 대한 어떠한 정보도 수집하지 않습니다.** 인터랙티브 대본, 듣기 챌린지, 이중 자막, 로컬 단어 저장 기능은 모두 브라우저 내에서만 작동하며, 개인 데이터가 당사로 전송되지 않습니다.
* **로그인은 선택 사항입니다.** 로그인은 오직 기기 간 저장된 어휘를 동기화하기 위해서만 존재합니다. 로그인을 선택하면 당사는 사용자의 **이메일 주소**를 수집하고, **명시적으로 저장한 단어**(주변 자막 줄 포함)를 당사 클라우드 데이터베이스에 저장합니다.
* **진단 정보는 옵트인 방식이며, 클릭 한 번으로 이루어집니다.** 자막 로드에 실패하면(재시도 실패 후에만 표시되는) 긴급 **"페이지 새로고침"** 버튼이 원클릭 진단 보고서(동영상 주소와 기술적 세부 정보)를 당사로 전송합니다. 이는 문제 해결을 위한 것입니다. 배너에 버튼 바로 옆에 이 사실이 명시되어 있으며, 자동으로 보고되는 정보는 없습니다.
* 당사는 사용자의 데이터를 판매하거나, 광고를 표시하거나, 제3자 광고·분석 추적기를 운영하거나, 사용자의 검색 기록을 추적하지 **않습니다**.

## 1. 수집하는 정보

### a. 로그인하지 **않는** 경우
확장 프로그램은 당사 서버에 개인 데이터를 수집, 전송, 저장하지 **않습니다**. 사용자의 언어 및 레이아웃 환경설정과 로컬 "저장된 단어" 카운터는 오직 사용자의 브라우저에만 보관됩니다(3항 참조). 계정, 이메일, 저장된 단어는 결코 사용자의 기기를 벗어나지 않습니다.

### b. 로그인을 선택하는 경우(선택적 계정)
로그인하면 저장된 어휘의 기기 간 동기화가 가능해집니다. 로그인 시 당사는 다음을 수집 및 처리합니다.

* **계정 데이터** — 사용자의 **이메일 주소**와 Firebase가 생성한 사용자 ID. 이는 사용자의 계정을 식별하고 저장된 단어를 사용자와 연결하는 데 사용됩니다.
* **저장된 어휘** — 시청 중 사용자가 명시적으로 저장을 선택한 항목만 해당됩니다. 저장된 각 항목에 대해 다음을 저장합니다.
  * 사용자가 선택한 **단어 또는 구문**;
  * 소량의 **자막 문맥** — 저장된 자막 줄과 그 앞뒤 줄(동영상의 기본 자막 언어로만 제공);
  * 확장 프로그램을 나타내는 **소스 태그**;
  * **타임스탬프**와 일일 저장 한도를 적용하기 위해서만 사용되는 일별 카운터.
* **진단 보고서** — 자막 로드에 실패하고 사용자가 오류 배너의 **"페이지 새로고침"** 버튼(보고서가 전송된다는 안내가 표시됨)을 명시적으로 누른 경우에만 해당됩니다. 각 보고서에는 웹사이트의 호스트명, 오류가 발생한 동영상의 주소(URL) 또는 ID, 사용자가 선택한 자막 언어 쌍(학습 중인 언어와 모국어), 확장 프로그램 버전, 브라우저의 인터페이스 언어, 확장 프로그램을 식별하는 소스 태그, 그리고 서버 타임스탬프가 포함됩니다. 보고서는 사용자가 로그인되어 있는 동안에만 전송되며, 계정당 하루 최대 1건으로 제한되고, 오로지 오류 조사 목적으로만 사용됩니다.

당사는 다음을 수집하지 **않습니다**: 사용자의 검색 기록, 시청한 동영상(사용자가 명시적으로 저장한 자막 텍스트와 사용자가 명시적으로 유발한 진단 보고서에 포함된 단일 동영상 주소는 제외), IP 기반 위치 추적, 광고 식별자, 추적용 쿠키, 또는 확장 프로그램 사용 방식에 관한 어떠한 분석 정보도 수집하지 않습니다.

> 사용자의 Lingogram 계정은 당사의 다른 Lingogram 확장 프로그램에서도 함께 작동합니다. 동일한 계정으로 로그인하면 저장된 어휘가 함께 동기화됩니다.

## 2. 정보 사용 방법

당사는 위 정보를 **오직** 다음 목적으로만 사용합니다.

* 사용자를 인증하고 세션 간 로그인 상태를 유지하기 위해;
* 저장된 어휘를 저장하고 기기 간 동기화하여 나중에 검토할 수 있도록 하기 위해;
* 남용을 방지하기 위해 저장 단어에 합리적인 일일 한도를 적용하기 위해;
* 사용자가 **"페이지 새로고침"** 버튼을 통해 명시적으로 신고한 자막 로드 실패를 조사하고 해결하기 위해.

당사는 여기서 설명한 동기화 및 진단 기능을 제공하는 것 이외의 목적, 즉 광고, 프로파일링 등의 목적으로 사용자의 정보를 사용하지 않습니다.

## 3. 로컬 저장소(사용자 기기 내)

확장 프로그램은 브라우저의 확장 프로그램 저장소(`chrome.storage`)를 사용하여 다음 정보를 오직 사용자의 기기에만 보관합니다.

* 사용자의 언어 및 자막 레이아웃 환경설정;
* 저장한 단어 수에 대한 로컬 카운트;
* 로그인한 경우: 인증 토큰, 이메일 주소, 사용자 ID(로그인 상태 유지를 위해), 그리고 세션 저장소에 보관되는 짧은 수명의 로그인 논스(nonce).

이 로컬 데이터는 4항에서 설명하는 경우(클라우드에 동기화되는 저장된 단어)를 제외하고는 결코 사용자의 브라우저를 벗어나지 않습니다. 로그아웃하면 인증 토큰, 이메일, 사용자 ID가 사용자의 기기에서 삭제됩니다.

## 4. 클라우드 저장소 및 제3자 서비스

로그인한 경우, 사용자의 계정과 저장된 어휘는 개발자가 Google Cloud 인프라에서 운영하는 **Google Firebase**(Firebase Authentication, Cloud Firestore, Secure Token Service)를 사용하여 저장됩니다. Google은 당사의 서비스 제공업체로서 이 데이터를 처리합니다. Google의 개인정보 처리방침은 https://policies.google.com/privacy 에서 확인할 수 있습니다. 접근 권한은 Firestore 보안 규칙에 의해 제한되어, 사용자는 자신의 데이터만 읽고 쓸 수 있습니다.

자막을 표시하기 위해 확장 프로그램은 사용자가 시청 중인 동영상에 대해 YouTube 플레이어가 이미 제공하는 자막(캡션) 트랙을 **사용자의 브라우저 내에서 직접** 읽습니다. 이 자막 처리 과정은 다음과 같습니다.

* 전적으로 사용자의 브라우저 내에서 이루어지며, 당사의 중간 프록시를 거치지 않습니다;
* 계정 데이터나 저장된 단어를 YouTube로 전송하지 않습니다;
* YouTube 자체의 개인정보 처리방침 및 이용약관의 적용을 받습니다.

## 5. 데이터 공유 및 판매

당사는 사용자의 개인 데이터를 판매, 대여, 거래하지 **않습니다**. 4항에서 설명한 인프라 제공업체인 Google Firebase를 제외하고는 어떠한 제3자와도 데이터를 공유하지 않으며, 법률상 요구되는 경우를 제외하고는 공유하지 않습니다. 당사는 사용자의 데이터를 광고 목적으로 사용하지 않습니다.

## 6. 데이터 보관 및 삭제

* **저장된 어휘**는 사용자가 삭제하거나 계정 삭제를 요청할 때까지 클라우드에 보관됩니다.
* **진단 보고서**는 문제 해결 목적으로만 보관되며, 계정 삭제 요청 시 함께 삭제됩니다(사용자 ID로 연결되어 있음).
* **로컬 데이터**는 언제든지 로그아웃(토큰, 이메일, 사용자 ID 삭제) 또는 브라우저에서 확장 프로그램을 제거하여 삭제할 수 있습니다.
* **계정 및 관련된 모든 클라우드 데이터**(이메일, 저장된 단어, 진단 보고서)를 삭제하려면 9항을 참고하여 개발자에게 문의하십시오. 당사는 합리적인 기간 내에 이를 삭제합니다.

## 7. 보안

인증 토큰은 사용자의 브라우저 확장 프로그램 저장소에 보관됩니다. 모든 네트워크 요청은 HTTPS를 통해 이루어집니다. 클라우드 데이터는 Firebase Authentication과 각 사용자를 자신의 레코드로 제한하는 Firestore 보안 규칙에 의해 보호됩니다. 어떠한 전송 또는 저장 방식도 100% 안전할 수는 없으나, 당사는 사용자의 정보를 보호하기 위해 합리적인 조치를 취하고 있습니다.

## 8. 아동의 개인정보 보호

이 확장 프로그램은 13세 미만(또는 해당 관할권의 동등한 최저 연령) 아동을 대상으로 하지 않으며, 당사는 이들로부터 고의로 개인 데이터를 수집하지 않습니다.

## 9. 본 방침의 변경

당사는 이 개인정보 처리방침을 수시로 업데이트할 수 있습니다. 중요한 변경 사항은 업데이트된 "최종 업데이트" 날짜와 함께 이곳에 반영됩니다. 업데이트 이후에도 확장 프로그램을 계속 사용하는 것은 개정된 방침에 대한 동의로 간주됩니다.
