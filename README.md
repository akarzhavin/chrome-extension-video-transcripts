# Language Learning Transcript Sidebar

A professional Chrome extension for language learners and accessibility. Displays synchronized transcripts and dual subtitles in a convenient sidebar for video players.

## Features
- Synchronized transcript sidebar
- Dual subtitle support
- Interactive navigation (jump to video time from text)
- Minimalist dark mode design

## Installation
1. Download the code
2. Run `npm install`
3. Run `npm run build`
4. Load the `build` folder as an unpacked extension in Chrome.
